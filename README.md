# ❄️ Elmotahida Cooling

> A modern and responsive website for **Elmotahida Cooling**, providing cooling and air conditioning solutions.

## 🌐 Live Website

**[Visit Website](https://elmotahida.netlify.app/)**

---

## 📖 About The Project

**Elmotahida Cooling** is a responsive company website designed to present the company's services, information, and contact details through a clean and modern interface.

The website was developed with a focus on **simplicity, responsiveness, performance, and user experience** across different devices.

---

## ✨ Features

* 📱 Fully responsive design
* 💻 Desktop, tablet, and mobile support
* 🎨 Modern and clean user interface
* ❄️ Cooling and air conditioning services showcase
* 📞 Contact information
* ⚡ Fast-loading static website
* 🔍 Basic SEO optimization
* 🗺️ Sitemap integration
* 🤖 Robots.txt configuration
